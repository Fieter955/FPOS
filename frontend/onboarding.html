📥 Cara Cepat: Import Excel

Punya ratusan barang? Jangan input manual! Gunakan file Excel/CSV untuk memasukkan semua data barang, harga, dan stok Anda sekaligus.

Format Kolom Header (Baris 1) Wajib:
KODEBARCODE, NAMAITEM, JENIS, MEREK, SATUAN, HARGAPOKOK, HARGAJUAL, STOK, STOKMIN, KETERANGAN, SUPPLIER

🧱 Setup Otomatis

Buatkan kategori dan satuan standar toko bangunan.

🎮 Coba-coba (Demo)

Isi aplikasi dengan data contoh untuk sekadar tes fitur.

⚖️ Setup Saldo Awal (Wajib)

Masukkan nilai kekayaan Zona Kerja Anda saat ini. Sistem akan otomatis memproses data ini menjadi jurnal akuntansi agar Neraca Anda seimbang sejak hari pertama.
